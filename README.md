# OOP-DoAn

Đồ án môn **Phương pháp phát triển phần mềm hướng đối tượng**.

## Đề tài
**MED-06 - Cổng quản lý sự kiện văn hóa và vé miễn phí**

## Quy trình nhánh
- main: nhánh ổn định.
- dev: nhánh phát triển chính.
- TV: bản PTTK Việt hóa được tạo từ dev, dùng để chuẩn bị báo cáo/trình bày.

## Công nghệ
- Phía máy chủ: TypeScript, NestJS
- Giao diện: Next.js
- Cơ sở dữ liệu: PostgreSQL
- Kho lưu trữ đối tượng
- Tìm kiếm
- Docker

## Giai đoạn hiện tại
Phân tích và thiết kế hệ thống (PTTK/UML), chuẩn bị báo cáo giữa kỳ.
