# OOP-DoAn

Đồ án môn Phương pháp phát triển phần mềm hướng đối tượng.

## Đề tài
MED-06 - Cổng quản lý sự kiện văn hóa và vé miễn phí.

## Quy trình nhánh
- `main`: nhánh ổn định, chỉ nhận thay đổi đã kiểm tra.
- `dev`: nhánh phát triển chính cho PTTK và mã nguồn.

## Công nghệ định hướng
- Backend: TypeScript, NestJS
- Frontend: Next.js
- Database: PostgreSQL
- Object storage
- Search
- Docker

## Giai đoạn hiện tại
Phân tích và thiết kế hệ thống (PTTK/UML).
